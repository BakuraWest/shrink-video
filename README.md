Compress a video down to a target file size so it fits Discord and other upload limits.

Everything runs in your browser. Your video is never uploaded to any server.

Open the site, drop in a video, pick a size, press Compress, then Download.

Notes:
- The first run downloads the encoder (about 30 MB).
- Long or high-resolution videos take a while. Keep the tab open.
- Files over about 1 GB may fail. A desktop browser works best.
